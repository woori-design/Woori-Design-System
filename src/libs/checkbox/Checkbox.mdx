# Checkbox

사용자가 선택 사항을 체크하거나 해제할 수 있는 클릭 가능한 컴포넌트입니다.

<Controls />

## 사용법입니다

Checkbox의 필수 사용법입니다.

```tsx
import "woori-design/dist/index.css"; // NextJS 프로젝트인 경우 추가
import { Button } from "woori-design";
```

필수 속성인 `size`를 설정하여 Checkbox의 크기를 설정합니다.

```tsx
<Checkbox size="large" />
```

### size

Checkbox의 크기를 결정합니다.

지원하는 size 크기는 `small`, `medium`, `large`입니다.

## 예시

### label

Checkbox의 내용물을 나타내는 label입니다.

```tsx
<Checkbox size="large" label="체크 박스" />
```

<Canvas of={CheckboxStories.Label} />

### type

Checkbox의 상태를 나타냅니다.

`default`, `warning`, `error` 세 가지 타입이 있습니다.

기본 값은 `default`입니다.

```tsx
<Checkbox size="large" label="default checkbox" type="default" />
<Checkbox size="large" label="warning checkbox" type="warning" />
<Checkbox size="large" label="error checkbox" type="error" />
```

<Canvas of={CheckboxStories.Type} />

### shape

Checkbox의 형태를 결정합니다.

`square`, `circle` 두 가지 타입이 있습니다.

기본 값은 `square`입니다.

```tsx
<Checkbox size="large" label="square checkbox" shape="square" />
<Checkbox size="large" label="circle checkbox" shape="circle" />
```

<Canvas of={CheckboxStories.Shape} />

### disabled

Checkbox의 동작을 막는 disabled 속성입니다.

이 속성이 true일 시, Checkbox는 비활성화됩니다.

```tsx
<Checkbox size="large" label="disabled checkbox" disabled={true} />
<Checkbox size="large" label="checked/disabled checkbox" disabled={true} checked={true}/>
```

<Canvas of={CheckboxStories.Disabled} />

### checked

Checkbox의 선택 여부 상태를 갖는 checked 속성입니다.

```tsx
<Checkbox size="large" label="checked checkbox" checked={true} />
<Checkbox size="large" label="not checked checkbox" checked={false} />
```

<Canvas of={CheckboxStories.Checked} />

### onChange

Checkbox의 선택 여부가 변경될 때 호출되는 이벤트 핸들러입니다.

```tsx
const OnChangeComponent = () => {
  const [checked, setChecked] = useState(false);

  const handleChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    setChecked(e.currentTarget.checked);
    alert(`체크 박스 상태: ${e.currentTarget.checked}`);
  };

  return <Checkbox size="large" checked={checked} onChange={handleChange} />;
};
```
