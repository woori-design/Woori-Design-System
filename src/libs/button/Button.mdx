# Button

사용자가 작업을 수행하는 데 사용되는 클릭 가능한 요소입니다. 사용자가 원하는 동작을 수행할 수 있도록 돕습니다.<br />

## 사용법

Button의 필수 사용법입니다.

```tsx
import "woori-design/dist/index.css"; // NextJS 프로젝트인 경우 추가
import { Button } from "woori-design";
```

필수 속성인 `size`와 `variant`를 설정하여 Button의 크기와 형태를 설정합니다.

```tsx
<Button size="xlarge" variant="box">
  Button
</Button>
```

### size

지원하는 size 크기는 `xlarge`, `large`, `medium`, `small`, `xsmall`입니다.

<Canvas of={ButtonStories.Size} />

`box`, `text` 총 2가지 종류의 variant가 있습니다.

## 예시

### colorScheme

Button의 컬러 속성을 지정합니다.

`primary`, `secondary` 총 2가지의 컬러 속성을 가집니다.

```tsx
<Button size="large" variant="box" colorScheme="secondary">
  large/box
</Button>
```

<Canvas of={ButtonStories.ColorScheme} />

### rounded

버튼의 border-radius 값을 나타냅니다.

기본값은 16px이며, `16px`, `100px` 2가지 중 적용할 수 있습니다.

```tsx
<Button size="large" variant="box" rounded={100}>
  Button
</Button>
```

<Canvas of={ButtonStories.Rounded} />

### disabled

버튼 클릭을 막는 disabled 속성입니다.

이 속성이 true일 시, 버튼은 비활성화됩니다.

```tsx
<Button size="large" variant="box" disabled={true}>
  Button
</Button>
```

<Canvas of={ButtonStories.Disabled} />

### width

버튼의 가로 길이를 조절할 수 있는 width 속성입니다.

최소 길이는 children width 길이이므로 이보다 작은 값을 적용할 경우, 적용되지 않습니다.

```tsx
<Button size="large" variant="box" disabled={true}>
  Button
</Button>
```

<Canvas of={ButtonStories.Width} />

### onClick

onClick 속성을 통해 버튼 클릭 시 원하는 이벤트를 할당할 수 있습니다.

```tsx
<Button
  size="large"
  variant="box"
  disabled={true}
  onClick={() => {
    alert("버튼이 클릭되었습니다.");
  }}
>
  Button
</Button>
```
