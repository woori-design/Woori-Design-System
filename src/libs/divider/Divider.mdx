# Divider

Divider는 섹션 간의 구분을 명확하게 보여주기 위한 **단순한 수평선 컴포넌트**입니다.  
디자인 시스템에 정의된 컬러와 두께 기준으로만 사용되며, 불필요한 커스터마이징은 지양합니다.

## 사용법

Divider의 기본 사용법입니다.

```tsx
import "woori-design/dist/index.css"; // NextJS 프로젝트인 경우 추가
import { Button } from "woori-design";

<Divider width="100%" thickness={1} />;
```

<Canvas of={DividerStories.Default} />

<br />

## 예시

모든 Props는 optional이며 기본값이 설정되어 있습니다.

| 이름        | 타입   | 설명                | 필수 | 기본값   |
| ----------- | ------ | ------------------- | ---- | -------- |
| `width`     | string | 가로 길이           | ❌   | `"100%"` |
| `thickness` | number | 선의 두께 (px 단위) | ❌   | `1`      |

<br />

### width

Divider의 가로 길이를 나타내는 `width` 속성입니다.

기본값은 `100%`입니다.

```tsx
<div style={{ display: "flex", flexDirection: "column", alignItems: "center" }}>
  <h4>width: 800px</h4>
  <Divider width="800px" />
</div>
```

<Canvas of={DividerStories.Width} />

### thickness

Divier의 두께를 나타내는 `thickness` 속성입니다.

기본값은 `1`입니다.

```tsx
<Divider width="300px" thickness={2} />
```

<Canvas of={DividerStories.Thickness} />

## 주의사항

컬러는 디자인 시스템 내 지정된 색상만 사용해야 합니다.

구분선 외 다른 목적으로 사용하는 것은 권장되지 않습니다.
