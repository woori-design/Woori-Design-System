# FloatButton

`FloatButton`은 화면 내 어디서나 쉽게 접근 가능한 동작을 제공하는 UI 요소입니다. 주로 화면의 모서리에 떠 있는 형태로 표시되며, 클릭하면 추가 메뉴 옵션이 나타나는 확장 기능을 제공합니다.

<Controls />

<br />

## 사용법

`FloatButton`의 기본 사용법입니다.

```tsx
import "woori-design/dist/index.css"; // NextJS 프로젝트인 경우 추가
import { FloatButton, MenuItem } from "@woori-design";
```

`size`와 `shape` 속성을 정의하여 버튼의 크기와 형태를 설정하고, `MenuItem` 컴포넌트를 기반으로 `children` 속성으로 정의하여 `FloatButton`을 구성합니다.

```tsx
<FloatButton size="md" shape="circle">
  <MenuItem icon="🔍" label="검색" />
  <MenuItem icon="🏠" label="홈" />
  <MenuItem icon="⚙️" label="설정" />
</FloatButton>
```

### 메뉴 상태 관리 예시

```tsx
import { useState } from "react";
import { FloatButton, MenuItem } from "@woori-design";

function App() {
  const [isMenuOpen, setIsMenuOpen] = useState(false);

  return (
    <div>
      <p>메뉴 상태: {isMenuOpen ? "열림" : "닫힘"}</p>
      <FloatButton size="lg" shape="circle" onToggle={setIsMenuOpen}>
        <MenuItem icon="🔍" label="검색" />
        <MenuItem icon="🏠" label="홈" />
      </FloatButton>
    </div>
  );
}
```
